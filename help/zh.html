👋 FaceReg / Reconize——人脸与问候

打开人脸程序，确认机器人能接收其数据，然后设置遇到人时它说什么、做什么。

Reconize 应用内操作

1. 打开应用并登录

在 Hub 的工具页打开 Reconize，点击 Open Reconize。在新标签页输入主办方提供的 Reconize 账号，点击 Login。

2. 查看活动总览

打开 Dashboard，核对已登记人数和今日检测数。在 Recent Activity 查看签到是否已记录。

3. 添加和查找参会者

打开 People，点击 Add Person。填写参会者资料并添加经同意的参考照片。保存后搜索参会者，打开记录核对。

4. 导入参会者名单

打开 Import Participants。CSV 或 Excel 选 Upload file，经授权的共享表格选 Google Sheet。用 Download Example 查看示例，确认识别出的姓名和照片列后再导入。 选择文件或表格后才会显示列预览。

5. 设置签到点

打开 Activities，输入名称并点击 Add。为活动选择摄像头和模式，点击 Open station。各签到点在独立窗口打开。

6. 使用签到画面

打开 Face Recognition，确认 Mode。在点击模式下，请来宾按 TAP TO SCAN。按提示允许摄像头并完成同意与签到步骤。

7. 注册摄像头工作站

在安装摄像头的电脑上打开 CCTV。填写唯一的工作站名称，选择活动和识别方式，然后点击 Register this station。按该工作站显示的选项继续。

8. 从其他设备打开 Reconize

打开 Connect，在同一 Wi-Fi 的设备上扫描你自己屏幕上的二维码。如果显示尚未共享，请主办方在主机上以网络模式启动 Reconize。

9. 核对出席人员

签到后打开 Attendees，对比已检测和已登记人数。更正漏记前，先核对该参会者的记录。

10. 查看已提交照片

打开 Upload History 查找提交识别的照片。找不到时，在原设备上确认上传是否完成。

11. 查找识别记录

打开 Recognition History，按姓名、编号或文件名搜索，并按结果筛选。获准保存副本时点击 Export CSV。

12. 查看活动统计

打开 Reports，比较各活动出席情况和检测时间线。按需要选择 Export Participants 或 Export Attendance。

13. 检查照片使用同意

打开 PDPA，搜索来宾。使用照片前确认最新状态。来宾在签到机上作答后，状态可能与登记时不同。

14. 批量处理活动照片

打开 Event Photos，点击 New Batch。选择摄影师授权的来源文件夹，按批次提示操作。需要在自己的云盘保留副本时再点 Connect Google Drive。

15. 运行视频实验

打开 Local Video Experiment，选择示例视频或获准使用的云盘批次。上传后选中视频并启动实验，查看本次抽样帧的检测数。 截图是首次使用时的页面。选中文件后才能点击 Upload video。

16. 核对活动与摄像头设置

打开 Settings，确认活动名称、日期和地点，选择签到模式和摄像头。保存后，在来宾到达前使用获准的测试数据试签。 向下滚动到 Save Settings。

17. 阅读隐私信息

从登录页打开 Privacy Policy，了解系统保存哪些信息、保存多久以及向谁提出删除请求。 向下滚动查看保留与删除章节。

Reconize 无法打开时

回到 Hub 的 Reconize 页面，检查应用是否运行，再打开 Reconize。摄像画面仍为黑屏时，允许浏览器使用摄像头并关闭占用它的其他标签页或应用。

连接识别与 Voice

在 Hub 的 Reconize 页面启动跟踪并查看状态。进入问候设置，打开问候、选择扬声器并保存。在 Voice 中用获准的测试参会者试问候。

选择适合工作的页面

打开 MICE 的 Reconize 页面 此页面有 3 个标签页。人脸管理程序通过“打开 Reconize”按钮打开。
